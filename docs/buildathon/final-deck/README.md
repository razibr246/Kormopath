# Final pitch materials

| File | What it is |
|---|---|
| `KormoPath-Pitch-Deck.pdf` | The 5-slide deck submitted to Devpost (problem, solution, how it works, business and developer). |
| `pitch-script.md` | Timed 3-minute talk track for the five slides, plus short answers to likely judge questions. |
| `project-description.md` | The short project description for the Devpost form. |
| `demo-video-captions.en.srt` | English captions for the 61-second silent demo video (upload together to YouTube). |

The animated presenting version (press `F` for full screen, `N` for notes) and the demo video are kept outside the
repository because of their size. Every number in the deck comes from `lib/eval-results.json` (run `npm run eval`,
shown on `/trust`) or from a sourced entry in `lib/data.ts`.
