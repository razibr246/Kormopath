# Documentation map

| Folder | What is in it |
|---|---|
| `architecture/` | System maps, feature inventory, user journeys, roadmap. |
| `apps/` | Per-app research and plans (AdmitBuddy, FeeGuard, HaatBazar, MediScan, Probaho, Shohoj), plus `health/` and `legal/` design notes. |
| `research/` | Competitor analysis, feature matrices, recommended integrations. |
| `reports/` | Audits, testing, production readiness and reliability reports. |
| `buildathon/` | Pitch scripts, demo script and the B2C model. |
| `buildathon/final-deck/` | The submitted 5-slide PDF, timed pitch script, project description and video captions. |
| `buildathon/alt-deck/` | An earlier draft deck (HTML; its media is kept locally). |

Project rules for contributors and coding agents live in `/AGENTS.md`; the product overview is in `/README.md`.
